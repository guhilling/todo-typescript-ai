# todo-typescript-ai

Node.js/TypeScript backend, derived from TaskFest's design and deployed on AWS. Most of the code
is generated by Claude and reviewed by Gunnar.

General working rules (branches and pull requests, TDD, cost questions, infrastructure applied by
a human) are in `~/.claude/CLAUDE.md`. This file holds only what is specific to this project.

## Project rules

- **Decisions live in `doc/decisions/`.** Read the relevant file before changing the stack,
  database access or networking, and update it in the same change as the behaviour.
- **Stack:** Fastify, Zod or TypeBox, Prisma, Vitest + Testcontainers, Biome, pnpm, pino. See
  `doc/decisions/technology-stack.md`. Open: validation library (decided later), network (the
  security team decides).
- **Authentication is plain OIDC**, provider-agnostic: Okta, Keycloak locally, Cognito in
  qa-testing. Provider differences are configuration, not code. See
  `doc/decisions/authentication.md`.
- **Prisma is the data access and migration tool.** Schema changes go through `schema.prisma` and
  Prisma Migrate, never hand-edited tables. See `doc/decisions/data-access-and-migrations.md`.
- **One `pg` `Pool` with RDS IAM authentication**, handed to Prisma via `@prisma/adapter-pg`:
  token as a password function, TLS verified against the RDS CA bundle. A fixed-password
  connection URL doesn't work at runtime. See `doc/decisions/rds-iam-authentication.md`.
- **Migrations run with a freshly generated token** in `DATABASE_URL`; `prisma.config.ts` can't
  compute it. Destructive migrations are called out in the pull request.
- **Check version-specific library APIs against current docs**, not memory, and record what was
  verified in `doc/decisions/`. See `doc/decisions/ai-generated-code.md`.
- **Gate before every commit:** `tsc --noEmit`, Biome and Vitest. The single command goes here
  once `package.json` exists.
- **Prices in docs carry their source.** A price that was not checked against the AWS price list
  stays marked "unverified" until it is.
