# Technology stack

Status: accepted (Gunnar, 2026-10-13), except where a row says "open".

## Context

Node.js is a runtime, not a framework like Quarkus: HTTP layer, validation, migrations, testing
and tooling are separate choices. The code is mainly generated by Claude (see
[ai-generated-code.md](ai-generated-code.md)), which favours explicit, conventional, widely used
libraries over implicit wiring and new ones.

## Decisions

| Concern | Quarkus equivalent | Choice | Why |
|---|---|---|---|
| Runtime | JVM | Node.js, current LTS | – |
| Language | Java | TypeScript, `strict` | Compile errors are the fastest feedback on generated code |
| HTTP framework | RESTEasy / Vert.x | **Fastify** | Plain functions and explicit plugins, schema-first, nothing hidden in a DI container. NestJS was considered: closest to Quarkus, but hides more |
| Request/response validation | Bean Validation | **Zod or TypeBox** (open: decided later, when the first endpoint is written) | Prisma generates model types, not request schemas. Types are erased at runtime, so input must be validated; derive types from the schema |
| Data access | Panache / JDBC | **Prisma Client** | See [data-access-and-migrations.md](data-access-and-migrations.md) |
| Schema migrations | Flyway | **Prisma Migrate** | Same decision file |
| Database authentication | – | RDS IAM via one `pg` `Pool` | See [rds-iam-authentication.md](rds-iam-authentication.md) |
| Testing | JUnit + Quarkus Test | **Vitest + Testcontainers** | Tests are the specification for generated code |
| Dev loop / build | Quarkus dev mode, Maven | **`tsx`** for dev, **`tsc --noEmit`** for type checking, plus `prisma generate` | – |
| Lint / format | Checkstyle, Spotless | **Biome** | One tool instead of ESLint + Prettier |
| Package manager | Maven | **pnpm** | – |
| Config | MicroProfile Config | Environment variables validated with the same schema library at start-up | Fail fast on missing config |
| Logging | JBoss logging | **pino** | Fastify's default logger |
| Authentication | quarkus-oidc | **OIDC**: Okta; Keycloak locally, Cognito in qa-testing | See [authentication.md](authentication.md). Authorisation model is open until the domain model exists |
| Network (public subnet vs NAT) | – | **Open: the security team decides** | See [network-and-nat.md](network-and-nat.md) |

## Consequences

- Dependencies are passed as plain function or constructor arguments; there is no container.
- A `prisma generate` step belongs in the build and in CI.
- Exact versions are not recorded here yet. They are fixed when `package.json` exists; none of the
  library choices above except `@prisma/adapter-pg` has been checked against current
  documentation.
